# MediQueue — Hospital Emergency Management System

A student mini-project demonstrating a priority queue and linked list using Python and Flask. This is an educational demo only, not a clinical triage tool.

## Run locally

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000. See `REPORT_TEMPLATE.md` for the report outline. The included Flask app requires Python; GitHub Pages cannot run the backend directly.
